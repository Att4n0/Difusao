This repository was made in Brazilian Portuguese, and is very much still a work in progress.
This python application uses csv files containing various substances and their respective mass transfer constants.
The user inputs a solute, a solvent, and parameters such as temperature and pressure, and the program returns the diffusion coefficients using the suitable equation.
Equations include Hirschfelder, Fuller and Brokaw models, with more to come.
The model is chosen based on the polarity of the molecules.
